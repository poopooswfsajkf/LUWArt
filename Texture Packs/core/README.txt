Hello! You should not copy this folder to make your texture pack.
This folder does contain useful information and dumped textures(which you should only copy the ones you plan to modify), but is not a texture pack base.
If you are looking to make a Texture Pack, please look inside the install zip file, as there should be a "TemplatePack".
For more information, please go to: https://github.com/benjaminpants/BaldiTexturePacks/wiki
